= Learn about Cloud Volumes ONTAP automation options
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
DevOps teams use a variety of tools to automate the setup and administration of their data center runtime environments. Besides NetApp Console, you can use several of these technologies for Cloud Volumes ONTAP automation, including NetApp Console APIs, ONTAP CLI procedures, and automation tools, such as Ansible and Terraform. The external automation tools are commonly based on an Infrastructure as Code (IaC) design.

== NetApp Console APIs

The NetApp Console provides REST APIs that you can use to programmatically administer Cloud Volumes ONTAP resources. The APIs support operations such as creating and administering Cloud Volumes ONTAP systems and adding aggregates and volumes on Amazon Web services (AWS), Microsoft Azure (Azure), and Google Cloud. The available API calls vary by cloud provider and by deployment type, including single-node and high-availability (HA) configurations.

You can use the Cloud Volumes ONTAP API workflows to automate a typical deployment and subsequent storage administration. Some of these workflows include preparation, creating a system, and administering storage, with provider-specific workflows for AWS, Azure, and Google Cloud.

== Terraform

Terraform is an open-source orchestration tool that uses declarative configuration files. NetApp provides a Terraform provider that you can use with Cloud Volumes ONTAP to automate and integrate your infrastructure based on IaC. For more information, refer to https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest[NetApp Terraform provider^].

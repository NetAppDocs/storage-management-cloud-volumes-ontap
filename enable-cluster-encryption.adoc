= Enable Cluster Network Encryption
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
ONTAP supports Cluster Network Encryption beginning with ONTAP 9.19.1. Cloud Volumes ONTAP supports this capability beginning with Cloud Volumes ONTAP 9.19.1. You can enable Cluster Network Encryption to protect cluster traffic that is not already protected by ONTAP IPsec.

Cluster Network Encryption helps reduce the exposure of east-west traffic within the cluster and strengthens protection for deployments that require encrypted cluster communications.

Cluster Network Encryption uses the following components:

* *Cluster Session Management (CSM)* manages communication between blades within and across ONTAP clusters.
* *Kernel TLS (kTLS)* provides TLS in the kernel for kernel-resident applications and protocols.

When you enable the `tls_ipsec` mode, CSM traffic uses TLS and other cluster network traffic uses IPsec. ONTAP generates and manages the certificates and backend IPsec policies required for the cluster network.

Cluster Network Encryption is supported on Cloud Volumes ONTAP 9.19.1 and later in the following configurations:

* *N2*: Non-shared HA configurations for existing deployments.
* *C3*: Shared HA configurations for new deployments.

Cluster Network Encryption is not supported on shared HA configurations using N2 or non-shared HA configurations using C3.

.Before you begin

* You must be running Cloud Volumes ONTAP 9.19.1 or later.
* You must have cluster administrator privileges.
* You must verify that your Cloud Volumes ONTAP deployment uses a supported configuration.
* You must plan the change according to your organization's change-management and security requirements.

== Enable Cluster Network Encryption

.Steps

. Connect to the Cloud Volumes ONTAP cluster CLI.

. Verify the current Cluster Network Encryption configuration:
+
[source,cli]
----
security cluster-network show
----
+
Confirm that the output shows the current values for `Enabled`, `Mode`, and `Status`. Before you enable the feature, `Enabled` should be `false` and `Status` should be `READY`.

. Enable Cluster Network Encryption in TLS and IPsec mode:
+
[source,cli]
----
security cluster-network modify -enabled true -mode tls_ipsec
----

. Verify that Cluster Network Encryption is enabled:
+
[source,cli]
----
security cluster-network show
----
+
Confirm that the output shows:

* `Enabled: true`
* `Mode: tls_ipsec`
* `Status: READY`

NOTE: The `tls_ipsec` mode uses TLS for CSM traffic and IPsec for other cluster network traffic.

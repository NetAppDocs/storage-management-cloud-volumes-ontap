= Subscribe and deploy Cloud Volumes ONTAP from AWS Marketplace
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/


[.lead]
Subscribe to the standalone Cloud Volumes ONTAP offering in AWS Marketplace, deploy a Console agent, and create your first system.


.Before you begin

Before you begin, make sure you have:

* An AWS account with permission to subscribe to AWS Marketplace. 

* To have NetApp Console create the IAM role automatically, you need AWS administrator permissions or the minimum permissions listed below.

[[aws-iam-role-permissions]]
+
[source,json]
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "CloudFormationStack",
      "Effect": "Allow",
      "Action": [
        "cloudformation:CreateStack",
        "cloudformation:DeleteStack",
        "cloudformation:DescribeStacks",
        "cloudformation:DescribeStackEvents",
        "cloudformation:GetTemplateSummary",
        "iam:CreateRole",
        "iam:DeleteRole",
        "iam:GetRole",
        "iam:PutRolePolicy",
        "iam:DeleteRolePolicy",
        "iam:GetRolePolicy",
        "iam:PassRole",
        "lambda:CreateFunction",
        "lambda:DeleteFunction",
        "lambda:GetFunction",
        "lambda:InvokeFunction"
      ]
    }
  ]
}

* You can create or use IAM roles in AWS for agent deployment.
* You can sign in to or create an account in the NetApp Console.

For full AWS agent deployment prerequisites, see link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html[Deploy a NetApp Console agent from the AWS Marketplace^].

== Subscribe to the standalone Cloud Volumes ONTAP offering in AWS Marketplace

Locate the standalone Cloud Volumes ONTAP offering in AWS Marketplace.

.Steps
. Go to AWS Marketplace using your AWS account with the required permissions.
. Locate the NetApp Cloud Volumes ONTAP standalone offering. AWS Marketplace provides two offerings for Cloud Volumes ONTAP:
** The standalone offering for Cloud Volumes ONTAP annual subscriptions 
** The NetApp Intelligent Service combined offering for NetApp data services and Cloud Volumes ONTAP subscriptions. 

. Choose the _standalone_ offering. These steps guide you through subscribing to the standalone offering.
. Review listing details and pricing terms.
. Subscribe and complete the checkout.
. After subscribing, AWS redirects you to the NetApp Console.

== Sign up or sign in to NetApp Console

Access the Console to continue with the setup after you complete the marketplace subscription.

.Steps
. On the Console page, select one:
* *Sign up* if you are a new user.
* *Sign in to NetApp Console* if you already have an account.
. If you select *Sign up*, complete the following:
.. Enter the required fields:
* Email
* Password
* Full name
* Company
* Country
.. Select *Next*.
.. Optional: Enter contact details such as address, city, state, postal code, and phone number.
.. Select *Sign up*.
.. Accept the license terms.
.. Verify your email address using the message from service@console.netapp.com.
. Sign in to the Console and complete authentication.


== Create your organization

Complete this step only if you are a first-time user or you do not already belong to a NetApp Console organization.

If you already belong to an organization, skip this section and continue to <<Associate your subscription>>.

Create an organization to manage users, roles, permissions, licenses, and systems.

.Steps
. Enter an organization name.
. Optional: associate a NetApp Support Site (NSS) account.
. Select *Create*.

== Associate your subscription

After you create your organization, the Console automatically tries to link your marketplace subscription to the organization.

If automatic association fails, manually associate your subscription. link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-subscriptions.html[Learn how to manage subscriptions^].


== Deploy a Console agent in AWS

After you associate the subscription, the Console automatically opens the agent deployment flow to manage your AWS resources and Cloud Volumes ONTAP systems.

To learn more about the permissions used during the agent deployment, see link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html[AWS permissions reference^].

.Steps
. Choose how to authorize agent deployment and follow the appropriate steps for your chosen method.

+

Create a role for me (recommended)::
NetApp Console creates the role needed for the agent deployment automatically. Review the role permissions here link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html[AWS permissions reference^].

+
NOTE: You need AWS administrator permissions or the minimum permissions in the <<aws-iam-role-permissions,JSON example above>>.

Assume role::
Specify an existing role ARN that the Console assumes for agent deployment. Ensure that the role has the necessary link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html[permissions].

AWS keys::
Enter your AWS access key and secret key for the agent deployment.

[role="tabbed-block"]
====

.Create role for me (recommended)
--
If you have AWS administrator permissions, use this option and select CloudFormation Quick Create to create the agent policy and role, and authorize deployment.

.. Add the AWS account ID and optionally, the external ID. The Console sets a default role name.

.. Select *Open CloudFormation Quick Create*.
.. Within the AWS CloudFormation Quick Create page, acknowledge the terms and select *Create stack*.
+
image:screenshot-stack-creation.png[width=50% Screenshot of the AWS CloudFormation stack creation page where you enter the AWS account ID and optionally, the external ID for the agent deployment role.]
+
.. When AWS configures the IAM role and generates the ARN, confirm and save the role.
--
.Assume role
--
If you already have a role with the required AWS permissions, provide its ARN so the Console can assume it to deploy the agent. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html#aws-permissions-agent[Learn about creating a role^].
--

.AWS keys
--
If you want to use access keys to authorize agent deployment, provide your AWS access key and secret key. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html#aws-permissions-agent[Learn about creating a role for a user^].
--

====

. Deploy the AWS agent: 
.. Configure Agent deployment details by setting or confirming the agent instance name and agent role.
.. Configure Networking configuration by selecting a VPC, subnet, key pair, public IP behavior, and proxy settings, if needed.
.. Configure Security group to allow inbound HTTP (80), HTTPS (443), and SSH (22) for troubleshooting access to the agent VM.

+ 
link:https://docs.netapp.com/us-en/console-setup-admin_create-console-agent/reference-ports-aws.html[View security group rules for AWS]
. Review the section summaries and select Add to deploy.

+
Track the deployment progress until it completes. You can expand the event logs to review detailed activity.
+
For full networking and permissions requirements, see:
+
* https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-1-set-up-networking[Set up networking for AWS Marketplace deployment^]
* https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-2-set-up-aws-permissions[Set up AWS permissions^]
* https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html[AWS permissions reference^]



.After you finish
The Console installs the Console agent and associates it with your Console organization. You can create your first Cloud Volumes ONTAP system or stay on the Systems page to add a system later.

== Add your first Cloud Volumes ONTAP system


After the Console deploys the agent, follow the steps in https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-quick-deploy-aws.html[Deploy Cloud Volumes ONTAP with Quick create in AWS^] to create your first system.

== Troubleshooting and recovery

Resume onboarding where you left off or retry agent deployment after a failure.

=== Resume setup

If you leave before onboarding is complete, continue from the last completed step.

.Steps
. Go to the NetApp Console home page.
. Select *Resume setup* to continue onboarding.

=== Recover from deployment failure

If the Console can't deploy the agent, use these steps to retry:

.Steps
. Download the deployment report.
. Review your configuration and logs.
. Select *Start over* to retry the deployment.
+
link:https://docs.netapp.com/us-en/console-setup-admin/task-troubleshoot-agent.html[Learn how to troubleshoot agent issues^].

= Subscribe and deploy Cloud Volumes ONTAP from AWS Marketplace
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
##Subscribe to Cloud Volumes ONTAP from AWS Marketplace and let NetApp Console guide you through onboarding. With a simple path from subscription to deployment, you can quickly get up and running with Cloud Volumes ONTAP. The guided experience simplifies the process from AWS Marketplace subscription to deployment, helping you deploy Cloud Volumes ONTAP without requiring extensive cloud or ONTAP expertise.##

Subscribing and deploying Cloud Volumes ONTAP from AWS Marketplace requires you to complete several steps in the Console. 

* Subscribe to Cloud Volumes ONTAP in AWS Marketplace.
* Sign up or sign in to the Console.
* Create your organization (if needed) and associate the marketplace subscription.
* Deploy a Console agent in AWS.
* Add your first Cloud Volumes ONTAP system.

##The deployment workflow has been automated with minimal input from you for subscription association, IAM role configuration, agent provisioning, and system initialization. Backend orchestration handles CloudFormation stack creation, VPC connectivity validation, and resource dependencies automatically. This reduces manual configuration steps and screen transitions, minimizing setup errors and helping you deploy Cloud Volumes ONTAP faster with fewer interruptions. As you progress through deployment, you can track your progress in the right panel.##

== Before you begin

Review these prerequisites before you start the onboarding workflow.

* You have access to an AWS account with permissions to subscribe in AWS Marketplace.
* You can create or use IAM roles in AWS for agent deployment.
* You can sign in to or create an account in the NetApp Console.

For full AWS agent deployment prerequisites, see link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html[Deploy a NetApp Console agent from the AWS Marketplace^].

== Subscribe in AWS Marketplace

Start the onboarding process by locating the Cloud Volumes ONTAP offering in AWS Marketplace.

.Steps
. Go to AWS Marketplace using your AWS account.
. ##Locate the NetApp Cloud Volumes ONTAP standalone offering. There are two offerings for Cloud Volumes ONTAP in AWS Marketplace: the standalone offering for Cloud Volumes ONTAP annual subscriptions, and the NetApp Intelligent Service (NIS) offering for NetApp data services and Cloud Volumes ONTAP subscriptions. Choose the standalone offering for this onboarding workflow.##
. Review listing details and pricing terms.
. Subscribe and complete checkout.
. After subscription, AWS redirects you to the NetApp Console sign-up or sign-in page.

== Sign up or sign in to NetApp Console

Access NetApp Console to continue with the setup after you complete the marketplace subscription.

.Steps
. On the Console page, select one:
* *Sign up* if you are a new user.
* *Sign in to NetApp Console* if you already have an account.
. If you selected *Sign up*, complete the following:
.. Enter the required fields:
* Email
* Password
* Full name
* Company
* Country
.. Select *Next*.
.. Optional: Enter contact details such as address, city, state, postal code, and phone number.
.. Select *Sign up*.
.. Accept the license terms.
.. Verify your email address using the message from service@console.netapp.com.
. Sign in to NetApp Console and complete authentication.


== Create your organization

Complete this step only if you are a first-time user or you do not already belong to a NetApp Console organization.

If you already belong to an organization, skip this section and continue to <<Associate your subscription>>.

Create an organization to manage users, roles, permissions, licenses, and systems.

.Steps
. Enter an organization name.
. Optional: associate a NetApp Support Site (NSS) account.
. Select *Create*.

== Associate your subscription

After you create your organization, the Console tries to associate your marketplace subscription to the organization automatically.

If automatic association fails, manually associate your subscription. link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-subscriptions.html[Learn how to manage subscriptions^].

== Monitor deployment

Monitor agent deployment progress so you can continue to system creation as soon as deployment completes.

.Steps
. Track the deployment progress dialog until completion.
. Optionally, expand event logs to review detailed activity.
. When deployment finishes, add your first Cloud Volumes ONTAP system, or stay on the Systems page and add a system later.


== Add your first Cloud Volumes ONTAP system

After the agent is ready, create your first Cloud Volumes ONTAP system in AWS.

.Steps
. From the post-deployment prompt, select *Add system*.
. Start the Cloud Volumes ONTAP system creation workflow.
. Complete the system configuration.

For detailed system deployment instructions, refer to https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-quick-deploy-aws.html[Deploy Cloud Volumes ONTAP with Quick create^].

== If setup is interrupted or fails

Use this section if you leave the onboarding flow before completion or if agent deployment fails. These steps help you resume where you left off or recover and retry deployment.

=== Resume setup

If you leave before completion, use the home page setup banner to resume from the last completed step.

.Steps
. Go to the NetApp Console home page.
. Select *Resume setup* to continue onboarding.

=== Recover from deployment failure

If deployment fails:

.Steps
. Download the deployment report.
. Review your configuration and logs.
. Select *Start over* to retry deployment.
+
link:https://docs.netapp.com/us-en/console-setup-admin/task-troubleshoot-agent.html[Learn how to troubleshoot agent issues^].

=== Separate PAYGO listing for Cloud Volumes ONTAP in AWS Marketplace
NetApp now offers a separate pay-as-you-go (PAYGO) listing for Cloud Volumes ONTAP in AWS Marketplace through NetApp Standalone Listing (NSL). NetApp previously introduced the Standalone Cloud Volumes ONTAP subscription to accommodate changes to the AWS Enterprise Discount Program (EDP). The PAYGO listing is now available under the same NSL offering alongside the Cloud Volumes ONTAP annual contract, making it easier to track PAYGO usage, monitor spillover charges, and manage consumption costs.
Both the Cloud Volumes ONTAP annual contract and the PAYGO listing remain separate from the NetApp Intelligence Services (NIS) annual contract and PAYGO listings, enabling separate billing for Cloud Volumes ONTAP capacity and data services.

=== Guidance for upgrading ONTAP hotfixes for specific Cloud Volumes ONTAP versions

ONTAP has released the following hotfixes compatible with Cloud Volumes ONTAP versions 9.14.1, 9.15.1, 9.16.1, 9.17.1, 9.18.1, and 9.19.1: 

* 9.14.1P18HF1
* 9.15.1P20HF1
* 9.16.1P16HF1
* 9.17.1P11HF1
* 9.18.1P8HF1
* 9.19.1P3HF1

For details, refer to https://security.netapp.com/advisory/ntap-20261021-0021[NTAP Security Advisory 20261021-0021^].

For your Cloud Volumes ONTAP systems, you might be prompted to upgrade to these hotfixes in the NetApp Console. However, these hotfixes are supported only when the Console agent version is 4.12.0 or later. If the Console agent version is earlier than 4.12.0, ignore the prompt.

https://docs.netapp.com/us-en/console-setup-admin/whats-new.html#console-agent-4-12-0[Console agent 4.12.0^]

=== Support for Denmark East and India South Central regions in Azure

You can now deploy Cloud Volumes ONTAP 9.12.1 GA and later in the Denmark East (denmarkeast) and India South Central (indiasouthcentral) regions in Azure. The following deployment types are supported:

* Single-node

* HA in a single availability zone using locally redundant storage (LRS) - For both Denmark East (denmarkeast) and India South Central (indiasouthcentral) regions

* HA in multiple availability zones using zone-redundant storage (ZRS) - For India South Central (indiasouthcentral) region only

For a list of all supported regions, refer to the https://www.netapp.com/cloud-volumes-ontap/supported-regions/[Global Regions Map under Azure^].

= Integrate Cloud Volumes ONTAP systems with Azure OneLake solution
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
You can integrate Cloud Volumes ONTAP with Azure OneLake to enable Azure AI services, such as Microsoft Copilot and OpenAI, to read data stored in your Cloud Volumes ONTAP systems. The integration uses ONTAP S3 multi-protocol access to connect Cloud Volumes ONTAP to an Azure OneLake lakehouse through an Azure on-premises data gateway (OPDG).

== Configure Cloud Volumes ONTAP S3

Configure ONTAP S3 multi-protocol access so that Azure OneLake can read data from your Cloud Volumes ONTAP NAS volumes. Refer to link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/enable-access-nas-data-task.html[Enable S3 client access to NAS data^] for more information.

.Steps
. After deploying Cloud Volumes ONTAP, select *Advanced View* > *System Manager* in NetApp Console to configure ONTAP S3 for the SVM.
+
.ONTAP S3 SVM configuration
image::screenshot-ontap-s3-svm-config.png[Screenshot of System Manager showing the ONTAP S3 configuration settings page for the SVM]
+
.ONTAP S3 access key settings
image::screenshot-ontap-s3-access-keys.png[Screenshot of System Manager showing the ONTAP S3 access key and certificate details for the SVM]

. Record the following details from the S3 configuration:
** Download the self-signed (system-generated) certificate.
** Copy the access key and secret access key.
** Use the same NAS LIF or create a new LIF.

=== Create an S3 NAS bucket with a read-only user

Create an S3 NAS bucket with a read-only S3 user to allow Azure OneLake to securely access your Cloud Volumes ONTAP data. Refer to link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/create-nas-bucket-task.html[Create an S3 NAS bucket^] for more information.

.Steps
. Create the S3 NAS bucket in System Manager.
+
.S3 NAS bucket creation
image::screenshot-s3-nas-bucket-create.png[Screenshot of System Manager showing the S3 NAS bucket creation interface in Cloud Volumes ONTAP]

. Select the NAS volume to associate with the S3 bucket.
+
.NAS volume selection
image::screenshot-s3-nas-volume-select.png[Screenshot showing the NAS volume selection step during S3 NAS bucket creation in System Manager]

. Verify the read-only permissions assigned to the S3 user.
+
.Cloud Volumes ONTAP S3 read-only permissions
image::screenshot-cvo-s3-readonly-permissions.png[Screenshot showing the read-only permissions configured for the Cloud Volumes ONTAP S3 user]

. Confirm that the NAS S3 bucket configuration is complete.
+
.Completed NAS S3 bucket configuration
image::screenshot-cvo-nas-s3-bucket-complete.png[Screenshot showing the completed NAS S3 bucket configuration in Cloud Volumes ONTAP]

== Configure Microsoft Fabric OneLake

Create an Amazon S3-compatible shortcut in your Azure OneLake lakehouse to connect to your Cloud Volumes ONTAP S3 bucket.

.Before you begin
* If you don't have a lakehouse, create one. Refer to link:https://learn.microsoft.com/en-us/fabric/onelake/create-lakehouse-onelake[Create a lakehouse with OneLake^] for steps.
* Ensure the S3-compatible bucket credentials meet the access and authorization requirements for S3 shortcuts.
* Verify that the On-Premises Data Gateway is listed in your Microsoft Fabric environment:
+
.On-Premises Data Gateway in Microsoft Fabric
image::screenshot-fabric-opdg-gateway-list.png[Screenshot of the Microsoft Fabric portal showing the On-Premises Data Gateway listed in the gateway management section]
+
.On-Premises Data Gateway details
image::screenshot-fabric-opdg-gateway-details.png[Screenshot showing the On-Premises Data Gateway details confirming it is installed and configured in Microsoft Fabric]

.Steps
. Open the lakehouse in Microsoft Fabric.
. Right-click on a directory within the Lake view of the lakehouse.
. Select *New shortcut*.
+
.New shortcut context menu
image::screenshot-lakehouse-new-shortcut.png[Screenshot showing the New shortcut option in the right-click context menu within the Azure OneLake lakehouse Lake view]

. Under *External sources*, select *Amazon S3 compatible*.
+
.Amazon S3 compatible source selection
image::screenshot-shortcut-s3-compatible-source.png[Screenshot showing the Amazon S3 compatible option selected under External sources in the OneLake shortcut creation wizard]

. Enter the Cloud Volumes ONTAP S3 configuration details, including the On-Premises Data Gateway.
+
.Cloud Volumes ONTAP S3 shortcut connection settings
image::screenshot-cvo-s3-shortcut-settings.png[Screenshot showing the S3 connection settings form with Cloud Volumes ONTAP S3 details and the On-Premises Data Gateway configured]

. Select *Next*.
. Enter a name for the shortcut.
. Optionally, enter a sub path to select a specific folder in the S3 bucket.
. Select *Create*.
+
The lakehouse automatically refreshes and the shortcut appears under *Files* in the Explorer pane.

. Confirm the Cloud Volumes ONTAP S3 connection in OneLake.
+
.Cloud Volumes ONTAP S3 connection confirmation
image::screenshot-cvo-s3-onelake-confirm.png[Screenshot showing the confirmed Cloud Volumes ONTAP S3 shortcut connection displayed under Files in the Azure OneLake lakehouse Explorer pane]

== Connect to Azure AI Search

After connecting Cloud Volumes ONTAP to Azure OneLake, you can connect a volume to Azure AI Search to create a search service.

For additional information, refer to link:https://learn.microsoft.com/en-us/azure/search/search-how-to-index-onelake-files[How to index OneLake files^].

= Integrate Cloud Volumes ONTAP systems with Azure OneLake
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
You can integrate Cloud Volumes ONTAP with Microsoft Azure OneLake to enable Azure AI services, such as Microsoft Copilot and OpenAI, to read data stored in your Cloud Volumes ONTAP systems. The integration uses ONTAP S3 multi-protocol access to connect Cloud Volumes ONTAP to an Azure OneLake lakehouse through an Azure on-premises data gateway (OPDG).

.Before you begin

Ensure that you have configured the following components before starting the integration process:

* An existing or new Cloud Volumes ONTAP cluster
* Azure on-premises data gateway
* A Microsoft Fabric subscription
* An Azure OneLake lakehouse

== Configure Cloud Volumes ONTAP S3

Configure ONTAP S3 multi-protocol access so that Azure OneLake can read data from your Cloud Volumes ONTAP NAS volumes.

.Steps
. After deploying Cloud Volumes ONTAP, select *Advanced View* > *System Manager* in NetApp Console to configure ONTAP S3 for the SVM. Refer to the link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/enable-access-nas-data-task.html[ONTAP documentation: Enable S3 client access to NAS data^] for more information.
+
image::screenshot-ontap-s3-svm-config.png[Screenshot of System Manager showing the ONTAP S3 configuration settings page for the SVM]
. From the S3 configuration:
.. Download the self-signed (system-generated) certificate.
.. Copy the access key and secret access key.
.. Use the same NAS LIF or create a new LIF.
. Create an S3 NAS bucket with a read-only S3 user to allow Azure OneLake to securely access your Cloud Volumes ONTAP data. Refer to the link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/create-nas-bucket-task.html[ONTAP documentation: Create an S3 NAS bucket^] for information.
+
[NOTE]
Ensure to select the correct NAS volume and assign read-only permissions to the S3 user during the S3 NAS bucket creation process to allow Azure OneLake to read the data.

== Configure the Azure on-premises data gateway

Install and configure an Azure on-premises data gateway on a VM inside your virtual network (vNET) to enable connectivity between Microsoft Fabric OneLake and your Cloud Volumes ONTAP system.

.Steps
. Install the Azure on-premises data gateway on a VM inside your vNET.
+
Refer to link:https://learn.microsoft.com/en-us/data-integration/gateway/service-gateway-install#download-and-install-a-standard-gateway[the Microsoft documentation: Download and install a standard gateway^] for installation steps.

. Log in to the Azure On-premises data gateway application with your email ID and register the gateway on your system.
+
Refer to link:https://learn.microsoft.com/en-us/data-integration/gateway/service-gateway-app[the Microsoft documentation: Manage the On-premises data gateway app^] for configuration steps.

== Configure Microsoft Fabric

Create an Amazon S3-compatible shortcut in your Azure OneLake lakehouse to connect to your Cloud Volumes ONTAP S3 bucket.

.Before you begin
* If you don't have a lakehouse, create one. Refer to link:https://learn.microsoft.com/en-us/fabric/onelake/create-lakehouse-onelake[Create a lakehouse with OneLake^] for steps.
* Ensure the S3-compatible bucket credentials meet the access and authorization requirements for S3 shortcuts.
* Go to *Settings > Resources and Extensions > Manage connections and gateways* and verify that the on-premises data gateway is listed in your Microsoft Fabric environment.

.Steps
. Open the lakehouse in Microsoft Fabric.
. Right-click on a directory within the *Lake* view of the lakehouse.
. Select *New shortcut*.
. For the source of the shortcut, select *External sources > Amazon S3 compatible*.
. Enter the Cloud Volumes ONTAP S3 configuration details, including the on-premises data gateway.
+
image::screenshot-cvo-s3-shortcut-settings.png[Screenshot showing the S3 connection settings form with Cloud Volumes ONTAP S3 details and the on-premises data gateway configured]

. Select *Next*.
. Enter a name for the shortcut. Optionally, enter a sub path to select a specific folder in the S3 bucket.
. Select *Create*. The lakehouse gets automatically refreshed and the shortcut appears under *Explorer > Files*.
. Confirm that the Cloud Volumes ONTAP S3 connection is established in OneLake.
+
image::screenshot-cvo-s3-onelake-confirm.png[Screenshot showing the confirmed Cloud Volumes ONTAP S3 shortcut connection displayed under Files in the Azure OneLake lakehouse Explorer pane]

== Connect to Azure AI Search

After connecting Cloud Volumes ONTAP to Azure OneLake, you can connect a volume to Azure AI Search to create a search service.

For additional information, refer to link:https://learn.microsoft.com/en-us/azure/search/search-how-to-index-onelake-files[the Microsoft documentation: How to index OneLake files^].

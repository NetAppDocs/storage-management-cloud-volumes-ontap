= Integrate Cloud Volumes ONTAP systems with Microsoft OneLake for AI and analytics
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// CHANGED: added "existing" per source doc
You can integrate Cloud Volumes ONTAP with https://community.fabric.microsoft.com/[Microsoft Fabric^] using https://learn.microsoft.com/en-us/fabric/onelake/onelake-overview[Microsoft OneLake^] to make existing Cloud Volumes ONTAP NAS data available to Microsoft analytics and AI services such as Power BI, Azure AI Search, OpenAI, and Microsoft Copilot. The integration requires no data movement or duplication. The integration uses https://docs.netapp.com/us-en/ontap/s3-multiprotocol/index.html[ONTAP S3 multi-protocol^] access to connect Cloud Volumes ONTAP to an existing Microsoft Fabric lakehouse.

.Before you begin

Verify that you have a running Cloud Volumes ONTAP system before starting the integration process.

== Create a root CA certificate and generate a certificate for the ONTAP S3 server
A certificate is required to secure HTTPS connections between Microsoft OneLake and the ONTAP S3 server. In this procedure, you create a root CA certificate on Cloud Volumes ONTAP and generate a signed certificate for the ONTAP S3 server.

For more information about creating and installing a CA certificate, refer to https://docs.netapp.com/us-en/ontap/s3-config/create-install-ca-certificate-svm-task.html[Create and install a CA certificate on an ONTAP S3-enabled SVM^].


.Steps

. Connect to the Cloud Volumes ONTAP system using SSH from a VM in your virtual network (vNet) or through Azure Bastion. 
. Create a root CA certificate.
+
[source,CLI]
----
security certificate create -vserver <svm_cvo> -type root-ca -common-name <svm_cvo_ca>
----
For example,
+
[source,CLI]
----
security certificate create -vserver svm_cvopsa2 -type root-ca -common-name svm_cvo_ca

The certificate's generated name for reference: svm_cvo_ca_159D1587CE21E9D4_svm_cvo_ca
----
+
. Generate a certificate signing request (CSR) and private key.
+
[NOTE]
Choose a fully qualified domain name (FQDN) for the ONTAP S3 endpoint (S3 server name), for example, `s3.cvo.com`, and specify it as the value for both the `-common-name` and `-dns-name` parameters. Note this value because you need it later when configuring the ONTAP S3 server. 
+
[source,CLI]
----
security certificate generate-csr -common-name s3.cvo.com  -dns-name s3.cvo.com
----
+
. The command generates a CSR and a private key. Copy and save both the values. You need the CSR in the next step and the private key later when configuring the ONTAP S3 service. Copy the CSR and the private key from the output.
. Sign the certificate request using the root CA certificate. When prompted, paste the CSR generated in the previous step.
** `ca_cert_name` - name of the root CA certificate
** `ca_cert_serial_number` - the CA serial number
+
[source,CLI]
----
security certificate sign -vserver svm_name -ca <ca_cert_name> -ca-serial <ca_cert_serial_number>
----
+
. The command returns a signed certificate. Copy and save the certificate content. You use this certificate and the private key generated in the previous step when configuring the ONTAP S3 server.


== Configure Cloud Volumes ONTAP S3

Configure ONTAP S3 multi-protocol access to allow OneLake read data stored in your Cloud Volumes ONTAP volumes.

// NOTE: source doc lists this navigation in a different order (Storage > Management, then select agent/system, then System Manager) - confirm which sequence matches the current UI
. Configure ONTAP S3 for the Cloud Volumes ONTAP system.
.. On NetApp Console, from the left navigation menu, select *Storage > Management*.
.. Select a Console agent and then click on the Cloud Volumes ONTAP system, and then, from the right menu options select *System Manager*. 
.. Enable S3 protocol access on the SVM. Refer to the link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/enable-access-nas-data-task.html[ONTAP documentation: Enable S3 client access to NAS data^] for information.
+
[NOTE]
During configuration, use the signed certificate and private key created in the previous section.
+
image::screenshot-ontap-s3-svm-config.png[width=300 Screenshot of System Manager showing the ONTAP S3 configuration settings page for the SVM]
.. Select *Reuse the data interface used for the SMB/CIFS or NFS protocol.* to reuse the existing LIF or configure a new data LIF.
. Copy and save the access key and secret access key. You need to use these credentials when creating the OneLake shortcut.
. Create a read-only group to access the S3 buckets from OneLake.
// CHANGED: fixed unbalanced bold markup around "Add"
.. After enabling the S3 server, configure the S3 server and add a new group. Select *Groups* and select *Add*.
.. Add a new group with the S3 user that was automatically created in the previous step, and assign it the `ReadOnlyAccess` policy. 
+
image::screenshot-onelake-s3-grp.png[width=300 Screenshot showing the ONTAP S3 read-only group configuration settings page for the SVM]

// CHANGED: heading updated to match source doc - this section only covers bucket creation, not S3 user creation
== Create an S3 NAS bucket
Create an S3 NAS bucket. Refer to the link:https://docs.netapp.com/us-en/ontap/s3-multiprotocol/create-nas-bucket-task.html[ONTAP documentation: Create an S3 NAS bucket^] for information.

[NOTE]
When creating the bucket, select the NAS volume that contains the data you want to make available through OneLake. 


== Install and configure Microsoft on-premises data gateway

// CHANGED: intro paragraph reworded per source doc
Install and configure a Microsoft on-premises data gateway on a VM in the same virtual network (vNet) as your Cloud Volumes ONTAP system. Install the Cloud Volumes ONTAP root CA certificate on the VM to establish trust for HTTPS connections to the ONTAP S3 server.

.Before you begin
// CHANGED: reworded and added detail about the data interface (LIF) resolution
* Ensure that there is network connectivity between the VM and the ONTAP S3 server you created in the previous section.
* Ensure that the ONTAP S3 server name configured earlier resolves to the IP address of the data interface (LIF) assigned to the ONTAP S3 server, and that the VM can successfully resolve this name.

.Steps

// CHANGED: reworded step to clarify the certificate is installed on the VM, not the SVM
. Install the CA certificate of Cloud Volumes ONTAP.
.. Open a browser on the VM and navigate to your S3 server: `\https://<CVO-S3-SERVER-URL>`
.. Select the lock icon on the address bar, and then select *Certificate details*.
// CHANGED: added detail on which certificate row to select
.. On the *Certificate Viewer* window, select the *Details* tab, and then select the first row of the root CA in the certificate list.
+
image::screenshot-onelake-dnld-cert.png[width=300 Screenshot showing the export certificate dialog box]
.. Select *Export...* and save the file locally in `DER` format.
+
image::screenshot-onelake-save-cert.png[width=300 Screenshot showing the save certificate dialog box]
.. Open the certificate file you saved, and select *Install Certificate...*.
+
image::screenshot-onelake-install-cert.png[width=300 Screenshot showing the certificate import wizard]
.. In the *Certificate Import Wizard*, select *Local Machine*, and place the certificate in *Trusted Root Certification Authorities* store.
+
image::screenshot-onelake-import-cert.png[width=300 Screenshot showing the certificate import wizard]
.. Follow the prompts to complete the certificate installation.
// CHANGED: reworded verification step with added detail
.. Verify the certificate installation by opening a new browser window and navigating to `\https://<CVO-S3-SERVER-URL>`. The ONTAP S3 server should return an XML access denied response, indicating that HTTPS communication is working correctly.
+
// CHANGED: specified "standard mode" gateway and "download and install" wording
. Download and install the Microsoft on-premises data gateway on the VM in standard mode. Refer to link:https://learn.microsoft.com/en-us/data-integration/gateway/service-gateway-install[Microsoft documentation: Install an on-premises data gateway^] for installation steps.


== Connect to OneLake
// CHANGED: intro sentence reworded per source doc
Create an Amazon S3-compatible shortcut in your Microsoft Fabric lakehouse to access data stored in your Cloud Volumes ONTAP S3 bucket.

.Before you begin

* An existing https://learn.microsoft.com/en-us/fabric/onelake/create-lakehouse-onelake[Microsoft Fabric lakehouse^] in your workspace.
// CHANGED: specified the gateway must be listed and connected
* In your environment, go to *Settings > Manage connections and gateways* and verify that your on-premises data gateway is listed and connected.
* The Cloud Volumes ONTAP root CA certificate is installed on the gateway VM.
* You have the following values from the previous steps: 
** ONTAP S3 server name (FQDN)
** Access key
** Secret access key


.Steps
// CHANGED: specified exact URL format and split the access key bullet into two
. In your lakehouse, create an Amazon S3-compatible shortcut to your Cloud Volumes ONTAP S3 bucket by using the following details. For the steps of creating the shortcut, refer to https://learn.microsoft.com/en-us/fabric/onelake/create-s3-compatible-shortcut[Microsoft documentation: Create an Amazon S3-compatible shortcut^].
** URL: The ONTAP S3 server in the format `\https://<S3-SERVER-FQDN>`
** Data gateway: The on-premises data gateway you configured earlier
** Access key ID
** Secret access key
+
image::screenshot-onelake-shortcut1.png[width=500 Screenshot showing the OneLake lakehouse Explorer pane with the Cloud Volumes ONTAP S3 shortcut connection]
// CHANGED: added detail about browsing files through the shortcut
. After the shortcut is created, verify that it appears under *Explorer > Files* in the lakehouse and that you can browse the files stored in the Cloud Volumes ONTAP volume through the shortcut.
+
image::screenshot-cvo-s3-onelake-confirm.png[Screenshot showing the confirmed Cloud Volumes ONTAP S3 shortcut connection displayed under Files in the OneLake lakehouse Explorer pane]

== Next steps: Index data with Azure AI Search

After creating the OneLake shortcut, you can configure Azure AI Search to index the data stored in your Cloud Volumes ONTAP volumes through OneLake. Azure AI Search indexing enables the data to be used by AI applications such as Microsoft Copilot and Azure OpenAI.

For more information, refer to link:https://learn.microsoft.com/en-us/azure/search/search-how-to-index-onelake-files[the Microsoft documentation: How to index OneLake files^].
